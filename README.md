# Stopwatch Project – ATmega32 ⏱️
👋 Hello, everyone!

This repository contains a mini project developed as part of my Embedded Software Basics Diploma at EDGES for Training.

📝 Project Summary
This project is a simple digital stopwatch implemented using the ATmega32 microcontroller. The stopwatch is displayed on a 7-segment display and controlled using three push buttons:

🔁 RESET – Resets the stopwatch to 00:00

⏸️ STOP – Pauses the timer

▶️ CONTINUE – Resumes counting

🎯 The goal of the project was to apply embedded systems fundamentals using low-level hardware control techniques.

🧰 Technologies & Features
🧠 Microcontroller: ATmega32

💡 Display: 7-Segment Common Cathode

🔌 Peripherals Used:

GPIO – For buttons and display control

Timers – To track and update time

External Interrupts – For responsive button input handling

📄 Project Details
Displays elapsed time on a multi-digit 7-segment display

Responds to user input via hardware buttons

Implements timing logic using internal microcontroller timers

Fully written in C for AVR architecture
